## 指令

默认指令名如下，全部可以在「指令设置」页里进行修改。

| 指令 | 参数 | 说明 | 权限 |
|------|------|------|------|
| `/雀魂播报` | 玩家昵称或雀魂ID | 添加监控并绑定当前群 | 管理员（可配置） |
| `/删除播报` | 玩家昵称或雀魂ID | 解除当前群绑定 | 管理员（可配置） |
| `/雀魂播报列表` | 无 | 查看本群监控列表和监控到期时间 | 所有人 |
| `/雀魂播报帮助` | 无 | 显示全部指令及说明 | 所有人 |
| `/雀魂牌谱` | 牌谱链接或牌谱ID | 拉取牌谱并逐局回放 | 所有人 |

> 网页「添加玩家」支持填昵称或账号 ID；群指令只按昵称搜索。
>
> 未上过雀杰的玩家只要添加账号池账号好友后也可进行播报。

- 本插件只能在群聊里使用；
- 同一个玩家可以绑定多个群，每个群都会播报；
- 开启「仅管理员可用」后，只有管理员列表里的账号能使用这些指令。

播报内容示例：

```
🀄 【雀魂对局播报】
玩家：云上归雁（雀圣一 638/1400）
近期战绩：[1234]
玉之间·四人南 2026-10-28 17:50
一位 42300 云上归雁 +55pt
二位 29500 某某 -12pt
三位 14800 某某 +8pt
四位 13400 某某 -51pt
牌谱：https://game.maj-soul.com/1/?paipu=...
和牌：东1局 云上归雁 荣和 某某 4番30符7700点 立直(1番)、平和(1番)
放铳：南2局 放铳给 某某 满贯12000点 役牌 中(1番)、宝牌(3番)
```

「和牌 / 放铳」这两行四麻对局只播报4番以上（包括流局满贯），三麻对局只播报倍满以上。

另外本局如果有以下两种情况会在播报之后再单独发一条：
- 胡到或点炮役满
- 升段或掉段


## 账号池

插件需要登录至少一个雀魂账号后才能读取观战列表和牌谱，可同时登录多个账号。建议使用小号，如果使用新创建的账号，需要至少有5场对局。

- **账号池**：账号池里**所有启用的账号都会同时登录**。
- **每日配额**：每个账号每天最多查询 200 次牌谱（待确认），页面会显示各账号当天用量；监控播报和手动「显示结果」共用这个额度。
- **牌谱权限**：当账号每日额度用完后，会显示已用完。
- **好友**：非好友的对局每次查询牌谱都会消耗一次查询额度，而好友的对局则是轮询好友观战列表，当好友对局结束后只查询一次即可播报，所以设置非好友的每日查询次数时尽量少或拉长非好友轮询间隔。
- **多账号**：如监控的玩家较多，可登录多个账号增加额度，查牌谱时始终使用所有登录账号里消耗最少的账号。


## 插件逻辑

- **发现对局**：每 30 秒轮询一次所有房间的观战列表（金/玉/王座的/三麻/四麻的东场/南场），如发现监控玩家就记下 uuid。
- **好友对局**：每 30 秒（可配置）轮询一次好友对局状态，当好友对局结束后，查询本牌谱。只消耗一次牌谱查询次数。
- **非好友对局**：每 120 秒（可配置）轮询一次牌谱，每次轮询消耗一次查询次数。
- **牌谱**：已查询过的牌谱会保存到本地，使用/牌谱查询指令再次查询时直接拉取本地，不消耗查询次数。牌谱保存一个月。


## 监控有效期

- 为防止永久播报，插件设置了监控有效期，到期后将不再播报，需要重新使用/雀魂播报 指令重置时间。如不需要此功能，可在插件设置里将监控有效期设置为不限制。
- 在监控列表页面点击绿色「更新」按钮，可重置该玩家监控时间。


## 网页功能

| 标签页 | 作用 |
|--------|------|
| 插件设置 | 启用/停用、好友轮询间隔、非好友轮询间隔、非好友每日播报次数上限、监控有效期、三麻监控、东场监控、自动同意好友申请、牌谱屋 API 节点。|
| 指令设置 | 修改指令名、设置管理员 |
| 账号池 | 添加/删除账号、启用开关、登录状态、牌谱权限 |
| 好友列表 | 每个在线账号的好友 |
| 监控列表 | 已监控玩家、绑定群、近期战绩、今日播报次数，更新按钮会重置监控时间 |
| 对局列表 | 各房间当前进行中的对局，支持房间/场风筛选、玩家搜索、查看 uuid、显示结果 |
| 插件日志 | 插件运行日志、查询记录；日志文件保留 30 天，超过一个月的会自动清理 |
